# Team: Start Here

If you are joining the Jamidaar mobile project for the first time:

1. Read `README.md`.
2. Follow `docs/SETUP.md`.
3. Run `npm install`.
4. Run `npx expo install --fix`.
5. Run `npx expo-doctor`.
6. Start with `npx expo start --clear`.
7. Use demo OTP `123456` while the production OTP backend is not connected.
8. Read `CONTRIBUTING.md` before pushing changes.
9. Create a feature/fix/ui branch instead of working directly on `main`.
10. Never commit passwords, API secrets, private keys, customer data, or `.env`.

For backend work, read `docs/BACKEND_INTEGRATION.md`.
